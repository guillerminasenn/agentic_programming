# Agentic Programming Resources

This repository is an example of how I organize a software development project
with agentic programming: clear project instructions, executable plans, and
reusable skills for coding agents.

The resources here include:

- [Presentations](presentations/): slides with best practices for agentic programming
  and organizing work with coding agents.
- [Plan template](plan-template.md): a starting point for planning work in small
  stages with dependencies, verification criteria, and execution records.
- [Skill template](skill-template.md): a starting point for documenting a reusable
  agent workflow.

I use the example of building a modern Norwegian mountain cabin, detailed in the
presentation, to illustrate this project organization. The cabin example is
organized as follows:

- [.agents/](../.agents/): reusable skills for building the cabin.
- [plans/](../plans/): plans for cabin construction.
- [docs/](../docs/): cabin specifications and requirements.
- [AGENTS.md](../AGENTS.md): instructions for agents working on the cabin example.
